## 中文

**测字问心 · ZiOracle** 是一款基于中国传统测字（拆字）文化的在线工具。输入一个汉字，即可拆解字形、分析五行、解读寓意，并引经据典、给出行动建议。三种用法随心选择——输入、随机抽字、一键随机，不输入也能测。

### ✨ 功能一览

| 模块 | 说明 |
|---|---|
| ✍️ **三种用法** | 输入汉字 / 随机抽字 / 一键随机，零输入也能用 |
| 📆 **每日吉字** | 首页按日期展示当日吉字，点击即可选用 |
| 📐 **拆字解字** | 自动识别字形结构（左右/上下/半包围/独体） |
| 🔮 **五行分析** | 200+ 部首五行库，覆盖所有常用汉字 |
| 📜 **引经据典** | 按五行引用《周易》《道德经》《论语》等经典 + 结构经典 |
| 💡 **今日心法** | 一句话提炼核心寓意 |
| ✅ **行动方案** | 按五行定制三条具体建议 |
| 💭 **20 个精选问题** | 事业/感情/财运/健康等，一键选用 |
| ⚔ **八字合参** | 结合生辰日主五行交叉解读（填则需填全） |
| ⭐ **收藏夹** | 收藏心仪的字，本地离线保存 |
| 🕘 **浏览历史** | 自动记录最近 50 个测过的字 |
| 🖼️ **卡片下载** | 五行色背景 PNG 卡片，一键发圈 |
| 🌐 **中英双语** | 全站一键切换 |
| 🌙 **亮暗主题** | 羊皮卷 + 暗色双主题，自动记忆偏好 |

## English

**ZiOracle** is an online tool based on traditional Chinese CeZi (character divination). Enter a Chinese character to deconstruct its form, analyze its five-element attribute, and read its meaning—with classical citations and action advice. Three modes: type, random draw, or quick random—works even without typing.

### ✨ Features

| Module | Description |
|---|---|
| ✍️ **Three modes** | Type / random draw / quick random, zero input needed |
| 📆 **Daily character** | A "character of the day" on the homepage |
| 📐 **Structure analysis** | Auto-detect left-right, top-bottom, enclosure, single-body |
| 🔮 **Five elements** | 200+ radical library covering all common characters |
| 📜 **Classical wisdom** | I Ching, Tao Te Ching, Analects citations by element + structure |
| 💡 **Heart method** | Core meaning in one line |
| ✅ **Action plan** | Three concrete suggestions by element |
| 💭 **20 preset questions** | Career, Love, Wealth, Health, etc. |
| ⚔ **BaZi synthesis** | Cross-read with your day master (all fields required) |
| ⭐ **Favorites** | Save characters offline (localStorage) |
| 🕘 **History** | Last 50 characters browsed |
| 🖼️ **Card download** | Element-colored PNG card |
| 🌐 **Bilingual** | Full Chinese/English toggle |
| 🌙 **Themes** | Parchment + dark, remembers preference |

### ⚠️ Disclaimer

Built upon traditional Chinese CeZi (character divination) culture, all content is for **cultural study and entertainment**. It is not scientific prediction, fate assertion, therapy, or any professional service.

Character deconstruction, element classification, and interpretations are subjective editorial work based on glyphs, meanings, and folk tradition. Different schools may differ; none is authoritative. This tool offers no medical, legal, financial, or therapeutic advice; action plans are general references only. Seek professionals if in serious distress.

Never use results as the sole basis for major decisions (marriage, investment, career, medical). CeZi is a mirror reflecting your current state of mind—your path is still yours to walk.

Pure front-end single-file app (plus the lunar library). No server, no tracking. Data stays in your browser only. Open-sourced for personal study and entertainment; commercial misuse is prohibited.
